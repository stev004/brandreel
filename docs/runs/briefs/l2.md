- textFit(manifest): estimatedLines <= maxLines for every element.
- hook(manifest): firstOnScreenTextMs !== null and <= 3000; the first visualChangeMs entry after 0 exists and is <= 3000.
- pacing(manifest): no gap between consecutive visualChangeMs entries (and between the last entry and totalDurationMs) greater than 3000ms.
- cta(manifest, script): closeStartMs <= 0.8 * totalDurationMs and script.close.line is non-empty.
