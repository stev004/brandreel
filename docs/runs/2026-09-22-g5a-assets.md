# G5a assets - 2026-09-22

Two Luna xhigh workers implemented the script boundary and the asset resolver. Parent reviewed both and independently ran the gates.

## File contract

`visual` accepts non-empty template, stock and gen directives. Broll has optional workspace-relative `clip`, optional `overlayText`, `captionSource` words/none and duration. A missing clip requires a stock/gen directive. Stack explicitly rejects broll rendering until G5c rather than routing it to Verdict.

`assets/manifest.json` has version 1 and an assets array keyed by beatIndex. Template entries are ready without files, generated entries are pending without files, and downloaded stock entries have a workspace-relative file, provider and available source/contributor metadata. `assets/veo-manifest.json` records pending prompts. Downloaded filenames include a content hash. Resolution failures preserve the previous manifest; successful script changes clear obsolete pending metadata. No real stock download is claimed: provider tests use injected fetch responses and no network.

The reviewer checked current provider documentation: [Pexels](https://www.pexels.com/api/documentation/) and [Pixabay](https://pixabay.com/api/docs/). Pexels uses the current v1/videos/search endpoint; Pixabay queries are bounded to its documented length limit. Keys are supplied only through environment variables and are not persisted.
