## Generated-clip proof

The committed `workspace/broll-demo/script.json` is an engineering fixture: a 2-second Broll beat precedes the existing demo. Its `words.json` contains three hand-authored dummy timings, not user audio. Reproduce from the repo root:

```sh
mkdir -p workspace/broll-demo/assets
ffmpeg -v error -y -f lavfi -i color=c=0x224466:s=160x284:r=30:d=2 -an -c:v libx264 -pix_fmt yuv420p workspace/broll-demo/assets/colour.mp4
node bin/assets.mjs workspace/broll-demo
node bin/conform.mjs workspace/broll-demo
node bin/compose.mjs workspace/broll-demo
node bin/lint.mjs workspace/broll-demo
```

The director used the installed Chrome executable via `--browser-executable` for compose. Conform used the explicit minterpolate fallback because RIFE is absent. The source became a 1080x1920, square-pixel, 60/1 clip with 120 frames over 2.000 seconds. Compose rendered 1140 frames, 19 seconds, 1080x1920 at 60/1. All 20 manifest text elements received real browser measurements.

Lint returned `ok: true`, no violations, and all 11 rules pass: width, height, fps, duration, safe-zone, text-fit, hook, pacing, CTA, overlap, pixel-bands. CTA dwell is 3000ms. Of 38 pixel samples, 34 were checked and 4 inside the 0-2000ms footage interval were excluded. Exclusion is explicit in `pixelBandCoverage`; footage receives no pixel-band proof because the flat-background heuristic does not apply to full-bleed video. Safe-zone, text-fit and geometry overlap still apply. Invalid interval metadata fails closed. A CLI regression proves geometry failures remain failures even when every pixel sample is footage.

The director inspected `frames/g5c-broll-demo-1000ms.png`: conformed video background, brand watermark, script overlay and highlighted timed word are present in their intended boxes. This is engineering acceptance, not a creative KEEP decision.
